# ajax-data-file-exchange
**Final high school project**: a CRUD web application using AJAX (Asynchronous JavaScript and XML) for data and file exchange. 
* The implementation allows for a responsive user experience by omitting traditional submit buttons, making the application dynamic and less 'machine-like'.
* The web server XAMPP was used to manage the user interface (with Apache Tomcat) and the main database containing two tables, one regarding the user parameters and the other one regarding the user's documets (with Apache and MySQL).
* The **Ajax_Tomcat-1.0-SNAPSHOT** folder contains the files for the **frontend**.
* The **Apache_Ajax_PHP** folder contains the files for the **backend**.

**BEFORE USING THE PROJECT**: import the database into MySQL, start XAMPP (Apache/Tomcat) and then open the frontend files in your browser.

**PLEASE NOTE: the application's interface and code comments are written in italian.**
